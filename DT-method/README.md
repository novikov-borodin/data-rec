# DT-method

LI-system data recovery using the Double Transform (DT) method:

for 1D signal recovery:
upload files with directories from the signals directory; run maple\DT.mw (or DT22.mw) in Maple 2017 or higher for 1D signal recovery (spectral domain); or run mcap\Amp.cir (or Amp22.cir) in Micro-Cap 12 or higher to change initial data in Amp.xlsx (or Amp22.xlsx).

for 2D image recovery:
upload files with directories from the images directory; run images\DTI-gr.mw in Maple 2017 or higher for grey jpg image recovery; or run images\DTI-clr.mw (Maple 2017 or higher) for color jpg image recovery.
