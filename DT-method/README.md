DT-method



LI-system data recovery using the Double Transform (TT) method:



for 1D signal recovery:

upload files with directories from the signals directory; run maple\\DT.mw in Maple 2017 or higher for 1D signal recovery (spectral domain); or run mcap\\Amp22.cir in Micro-Cap 12 or higher to change initial data in Amp.xlsx.



for 2D image recovery:

upload files with directories from the images directory; run images\\DTI-gr.mw in Maple 2017 or higher for grey jpg image recovery; or run images\\DTI-clr.mw (Maple 2017 or higher) for color jpg image recovery.
