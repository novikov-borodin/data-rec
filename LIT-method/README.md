# LIT-method

LI-system data recovery using the Linear Invariant Transform (LIT) method:

1. Novikov-Borodin A.V. Correction, Reconstruction and Modeling of Experimental Data using LI Transforms. - Journal of Data Science and Intelligent Systems, Vol. 00(00) 1-13, 2026. https://doi.org/10.47852/bonviewJDSIS62028448. 

for 1D signal recovery:
upload files with directories from the signals directory; run signals\LIT.mw in Maple 2017 or higher for signal recovery;  

for 2D image recovery:
upload files with directories from the images directory; run images\LIT-gr.mw (Maple 2017 or higher) for grey jpg image recovery; or run LIT-clr.mw (Maple 2017 or higher) for color jpg image recovery.
